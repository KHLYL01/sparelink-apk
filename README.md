## 📝 عن التطبيق (About)
**SpareLink** هو تطبيق أندرويد متكامل يهدف إلى سد الفجوة بين أصحاب السيارات وموردي قطع الغيار. سواء كنت تبحث عن قطع جديدة أو مستعملة، يوفر لك التطبيق تجربة بحث ذكية بناءً على نوع السيارة، الموديل، ورقم الشاسيه.

## 🛠 المتطلبات (Requirements)
- نظام أندرويد 6.0 (Marshmallow) أو أحدث.
- اتصال نشط بالإنترنت.
- تفعيل خاصية "تثبيت التطبيقات من مصادر غير معروفة" (لأن التحميل من خارج المتجر).
